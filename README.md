# 🌟 Why This Project?

Imagine solving a puzzle without touching your laptop.

This project demonstrates how **Artificial Intelligence** and **Computer Vision** can create intuitive, futuristic user interfaces. Instead of clicking tiles with a mouse, users simply perform hand gestures in front of their webcam to interact with the puzzle.

It is a perfect blend of:

* 🤖 Artificial Intelligence
* 👁️ Computer Vision
* 🌐 Web Development
* 🎮 Interactive Gaming
* ✨ Human-Computer Interaction

# ⚙️ How It Works

```text
📷 Webcam
      │
      ▼
🖐️ Hand Detection
      │
      ▼
👆 Gesture Recognition
      │
      ▼
🎮 Puzzle Control
      │
      ▼
🧩 Tile Movement
      │
      ▼
🏆 Solve the Puzzle
```

Every movement of your hand is captured through the webcam, processed using computer vision algorithms, translated into game controls, and instantly reflected on the puzzle board.

# 🎮 Gameplay

1️⃣ Launch the application.

2️⃣ Allow webcam access.

3️⃣ Keep your hand within the camera frame.

4️⃣ Perform the supported hand gesture.

5️⃣ Move puzzle tiles naturally.

6️⃣ Arrange all tiles in the correct order.

7️⃣ Celebrate when the puzzle is solved! 🎉
